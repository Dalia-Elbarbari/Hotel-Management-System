# Hotel Management System

A comprehensive desktop-based Hotel Management System developed using Java and Java Swing, designed to simulate the operational environment of a modern hospitality business. The application follows the Model-View-Controller (MVC) architectural pattern and applies object-oriented design principles to ensure modularity, maintainability, and clear separation of responsibilities.

The system supports multiple user roles, including Administrators, Employees, and Guests, each with dedicated functionalities and controlled access privileges. Core operations such as user account management, reservation handling, booking workflows, and payment processing are integrated into a unified platform to provide a structured and efficient management experience.

To maintain persistent data storage without relying on an external database system, the project implements file-based data management mechanisms for handling user records, authentication processes, and operational information. Additional validation and exception-handling procedures were incorporated to enhance system reliability and maintain data consistency throughout application execution.

### Technologies Used

* Java SE
* Java Swing
* MVC Architecture
* Object-Oriented Programming (OOP)
* File Handling and Data Persistence
* NetBeans IDE

### Concepts Applied

* Software Design Principles
* User Authentication and Authorization
* Role-Based Access Control
* Exception Handling
* Modular Application Development
* Desktop User Interface Design
